# Netflix Viewing Analysis

Personal Netflix viewing history analysis to understand watch patterns, content preferences, and time-of-day behavior.

## Questions I was asking

- When do I actually watch — and does that match when I think I watch?
- Which content types (series vs. films) dominate my viewing time vs. viewing sessions?
- Are there seasonal patterns in consumption?

## Stack

Python — pandas, matplotlib, seaborn

## Files

```
Netflix_Streaming_Analysis.ipynb   # Full analysis
ViewingActivity.csv                # Exported Netflix viewing history
```

## How to use with your own data

Export your Netflix viewing history from: Account → Security & Privacy → Download your personal information → Viewing activity
